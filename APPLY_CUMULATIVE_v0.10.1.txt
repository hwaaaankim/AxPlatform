AxPlatform v0.10.0 + v0.10.1 개선 코드 누적 패치

이 압축의 기준과 범위
- 처음 업로드하신 AxPlatform(1).zip의 v0.9.1 프로젝트를 기준으로 비교했습니다.
- v0.10.0 개선과 v0.10.1 추가 개선을 모두 포함한 최종 변경/추가 코드만 담았습니다.
- v0.10.0 또는 v0.10.1 개별 패치를 먼저 적용할 필요가 없습니다.
- 이미 v0.10.0을 적용한 프로젝트에도 이 누적 패치를 같은 경로로 병합할 수 있습니다.
- 전체 프로젝트/신규 설치본이 아닙니다. 변경되지 않은 소스는 들어 있지 않습니다.

적용 방법
1. Spring Boot 실행을 중지하고 기존 프로젝트를 백업합니다.
2. 이 압축의 src 내용을 기존 프로젝트의 같은 src 경로에 병합하여 덮어씁니다.
   기존 src 폴더를 삭제하거나 폴더 전체를 대체하지 마세요.
   이 압축에 없는 기존 파일은 반드시 그대로 유지합니다.
3. pom.xml을 기존 프로젝트 루트의 같은 파일에 덮어씁니다.
4. Eclipse에서 Refresh(F5) → Maven > Update Project → Project > Clean을 실행합니다.
5. 기존 설정으로 Spring Boot를 다시 실행하고 브라우저를 강력 새로고침합니다.

설정 및 DB
- 추가 SQL 실행은 없습니다. DB 초기화/재생성도 하지 않습니다.
- config/application-private.yml과 실제 DB 비밀번호/API 설정은 기존 파일을 유지합니다.
- 기존 업로드 자료, 저장 폴더, 저장소 식별 파일은 그대로 유지합니다.
- .git, target, node_modules, 개인 설정, 운영/테스트 생성 자료는 포함하지 않았습니다.

포함한 v0.10.0 개선
- 4가지 시작 방식별 기본정보 우선 입력과 실제 원본에 맞춘 질문.
- 업로드 직후 내용 확인/직접 편집/AI 대화 편집 연결.
- 'N개 시트로 계속' 버튼을 이전 버튼과 같은 하단 영역의 오른쪽에 배치.
- AI 셀 수정, 열/계산열 생성, 오류 임시 처리/제거, 행 추가/삭제.
- 데이터 확인, 검색/필터/정렬/그래프 보기 설정과 기본값.
- 저장 이후 행 추가, 엑셀 추가/교체, 수식 유지/확장과 자료 관리.
- 대기 상태의 정기 조회 때문에 전체 화면 로딩이 반복되는 문제 수정.

포함한 v0.10.1 개선
- 200행/4,000셀을 한 회차 처리량으로 두고 여러 회차로 데이터를 누적.
- 생성/사진 판독/기존 행 범위 편집의 서버 진행 위치 기록.
- 결과 적용 후 다음 구간 요청, 실패한 구간 재개, 중복 요청/적용 방지.
- 사진 대기 목록 보존, 원본 그룹을 나누어 등록, 기존 표에 이어 추가.
- 미완료 작업 원본 연결 보호, 처리 종료 후 연결 정리.
- 같은 열의 새 시트로 이어가기 및 실패 시 대상 시트 재사용.
- 처리 한도에서 성급하게 완료하지 않도록 끝 위치 확인.
- 질문 답변 및 AI 지침 전체 교체 시 적용 데이터와 처리 위치 유지.
- 계정/저장 한도와 원본 문제를 구분하며 완료 데이터/진행 위치 보존.

검증
- 검증된 최종 src 전체와 pom.xml을 원본에 이 패치만 병합해서 재현하는지 검사했습니다.
- 운영 Java 104개/테스트 Java 25개 컴파일, JUnit 고유 195개 중 194개 통과.
  외부 선택 파일이 필요한 기존 검사 1개는 보류, 실패는 없습니다.
- DOM 회귀 25개 명령, JavaScript 42개 문법, Thymeleaf 30개 화면 통과.
- 실제 유료 AI API 호출 및 운영 서버 배포는 수행하지 않았습니다.
