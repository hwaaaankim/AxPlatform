AxPlatform v0.9.0 — 저장 데이터 중심의 테이블 대시보드·여러 보기·계산 열
적용 기준: v0.8.0까지 반영한 프로젝트. 이 ZIP은 추가·수정 파일 패치입니다.

변경된 기본 흐름
사진 / 대화 / 직접 입력 / Excel 가져오기 → 편집·가공 → 전체 시트 저장 →
데이터 센터의 원본 테이블 자동 표시 → 필요할 때 조회 조건·계산 열·보고서·다운로드.
보기 하나를 만들기 전에 저장 데이터 전체를 먼저 확인합니다.
업무 목록의 '데이터 센터 열기'로 저장된 프로젝트에 바로 들어갑니다.

적용 순서
1. 실행 중인 앱을 종료하고 현재 프로젝트를 백업합니다.
2. 압축 안 파일을 pom.xml이 있는 프로젝트 루트에 같은 경로로 덮어씁니다.
   이 ZIP은 전체 신규 프로젝트가 아닙니다. 기존 v0.8.0 소스 위에 적용하세요.
3. Eclipse: Refresh → Maven > Update Project → Project > Clean → 앱 재실행.
4. 브라우저 강력 새로고침 후 엑셀 업무 목록 → 데이터 센터 열기를 누릅니다.
   Windows: Ctrl+F5, Mac: Cmd+Shift+R. 정적 리소스 버전은 0.9.0입니다.

이번 버전에는 추가 SQL과 설정 변경이 없습니다.
이미 적용한 13번 SQL(V006), LONGTEXT 및 max_allowed_packet 설정을 유지합니다.
config/application-private.yml, dev/test 개인 설정, DB, 저장 자료를 교체하지 않습니다.
v0.8.0에서 저장한 표는 다시 업로드할 필요가 없습니다. 기존 저장 보기 역시 읽을 수 있습니다.
개인 키·비밀번호·사용자 Excel 원본·실행 결과 파일은 패치에 포함하지 않았습니다.

처음 사용할 버튼
- 조회 조건: 거래처 = 원하는 거래처 AND 중량 >= 원하는 값처럼 여러 조건을 적용합니다.
- 정렬·표시 열: 보일 열과 최대 4개 우선순위 정렬을 고릅니다. 열 제목도 눌러 정렬할 수 있습니다.
- 계산 열 추가: 합계/곱셈/IF/SUMIF/VLOOKUP/INDEX-MATCH 또는 직접 수식을 미리보고 저장합니다.
- 보고서 만들기: X축 묶음 기준 여러 개와 Y축 집계값 여러 개를 선택해 표·그래프로 봅니다.
- 현재 보기 저장: 조건·표시 열·정렬·집계·그래프 설정을 이름별로 저장합니다.
- 다운로드: 현재 보기 전체 결과 XLSX/CSV 또는 모든 시트·수식이 포함된 원본 전체 XLSX.
