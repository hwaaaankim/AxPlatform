AxPlatform v0.2.0 → v0.3.0 업데이트 안내
기준: 이미 소스 import 및 V001/V002 SQL 적용 완료, MariaDB DB 이름 AxPlatform.

A. 적용 순서

1) 실행 중인 앱을 중지합니다. 기존 개인 설정과 자료를 보관한 상태에서 진행합니다.
2) HeidiSQL에서 기존 AxPlatform을 선택하고 db/manual/06_V003__ai_and_sheet.sql 전체를 복사·실행합니다.
   이 파일은 ap_ai_run/ap_sheet와 12개 행동·15개 의존을 추가합니다. 기존 회원·정책·자료를 지우지 않습니다.
3) 07_VERIFY_V003.sql 전체를 실행하여 V001/V002/V003 기록과 신규 테이블/컬럼을 확인합니다.
   첫 SQL 오류에서 멈추고 그 오류를 해결한 다음 진행하세요. DDL 전체가 자동 롤백된다고 가정하지 않습니다.
4) 소스 ZIP의 AxPlatform 폴더 안 파일을 기존 pom.xml이 있는 프로젝트 루트에 같은 경로로 덮어씁니다.
   기존 config/application-private.yml은 유지합니다. 새 import는 필요 없습니다. 이전 파일을 삭제할 항목은 없습니다.
5) 기존 private 파일의 ax.integrations.openai.enabled를 true로, api-key를 본인 키로 입력합니다.
   model=gpt-6-astra, reasoning-effort=high 등 비밀이 아닌 값은 기본 설정·예제에 작성되어 있습니다.
   기존 openai 블록의 false/빈 값이 공통 값을 덮어쓰므로 이 두 항목을 반드시 확인합니다.
6) Eclipse Refresh(F5), Maven Update Project, Clean 후 JDK17로 실행합니다.
   Maven jar plugin은 3.4.2로 유지했습니다. Working Directory는 프로젝트 루트여야 합니다.
7) /admin/login에서 기존 관리자 계정으로 로그인하고 ‘업무 화면 열기’로 본인 시험 공간을 사용합니다.
   일반 고객에게는 권한관리에서 필요한 신규 행동과 의존을 배정·검토·적용합니다.

DB를 다시 삭제하거나 V001/V002/초기화 SQL을 다시 실행하는 업데이트가 아닙니다.
V003은 등급별 현재 배정을 자동으로 늘리지 않습니다. 기존 관리자 암호도 초기화하지 않습니다.

B. 이번에 추가한 실제 동작

- 일곱 업무별 예시/질문/다음 행동 안내와 현재 정보로 AI 업무 제안 만들기.
- OpenAI Responses API 호출과 Java 서버의 허용 도구만 사용하는 자료/현재 초안/현재 표 조회.
- 본인 초안에 연결하고 명시 선택한 PNG/JPG/TXT 해석. 최대 3개, 합계 6MB.
- 확인 내용·추정·질문·경고·변경 제안 미리보기, 이전 제안으로 더 이야기하기, 선택 항목 반영.
- AI 작업 상태/취소/오류/기준 버전·원래 로그인 세션/멱등성, 현재 권한 재검사.
- EXCEL 기본 표의 열·행·셀·문자/숫자/날짜·단위·폭 편집, DB 적용, 한 단계 서버 되돌리기.
- 실제 데이터 XLSX와 열만 있는 빈 입력 양식 XLSX를 각각 다운로드.
- 열 구조/행 추가/행 삭제/셀 수정/출력 권한 분리. AI 반영과 되돌리기도 실제 변경 권한 검사.
- EXCEL 초안 복제 시 열 구조만 새 초안으로 복사하고 실제 데이터 행·행 ID는 복사하지 않습니다.

C. 저장/취소와 작업 한도

‘업무 요약’은 제목·다섯 답변·첨부 연결입니다. 기존 요약 저장/취소는 이 범위입니다.
‘표 적용’은 ap_sheet의 열/행/셀을 서버에 저장합니다. 표 되돌리기는 직전 표를 새 버전으로 적용합니다.
‘AI 제안 취소’는 미반영 제안을 취소하고 기존 수동 요약/표를 되돌리지 않습니다.
AI 검수 가능(READY)은 아직 반영되지 않은 제안이며 APPLIED가 선택 반영 완료입니다.
AI 요청 이후 수동 저장으로 버전이 바뀌면 기존 제안을 덮어 적용하지 않고 최신 자료로 재요청합니다.
다시 로그인해 다른 원래 세션이 된 경우 과거 제안은 조회할 수 있어도 새 세션에서 곧바로 반영하지 않습니다.

기본 모델 gpt-6-astra/high, 출력 토큰 최대 16000, 원격 요청 120초, 전체 작업 300초,
도구 최대 6라운드, 계정당 동시 2개/UTC 하루 시작등록 30개, worker 2개입니다.
실패·취소된 작업도 등록 횟수에 포함됩니다. 자동 유료 재시도와 비용 환불 약속은 없습니다.
표 제한은 20열·200행, 셀 2,000자, 전체 2MB, 숫자 유효숫자 최대 15자리입니다.
전화/코드/앞자리 0은 문자 형식을 선택하고 날짜는 YYYY-MM-DD로 입력합니다.

D. 이번 완료로 표시하지 않는 범위

기본 표 기능과 AI 제안 기반을 추가한 증분 버전입니다. 전체 기획의 P2 완료는 아닙니다.
XLSX/CSV/PDF 업로드 추가·리셋·복구, 수식 엔진/재계산, 집계·그래프/저장 보기,
Word/HWP/PPT 실제 문서 편집·출력, CRM/일정 실업무 엔진, 앱 실행 패키지, 외부 발송·결제는 후속입니다.
Java 내부 도구 계층은 외부 MCP 클라이언트에 공개한 표준 MCP 서버와 다릅니다.
실제 OpenAI 키로 실호출·사진 품질·타사 대비 사용성 우위는 검증하지 않았습니다.
이번 검수 결과의 실제 범위는 docs/TEST_REPORT.txt, 기획 대조는 docs/P03_GOAL_AUDIT.txt를 확인하세요.
