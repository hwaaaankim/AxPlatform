AxPlatform v0.8.0 — 원본 Excel 수식·문제 셀 바로가기·복원 가능한 임시 처리
적용 기준: v0.7.0까지 반영한 프로젝트. 이 ZIP은 추가·수정 파일 패치입니다.

적용 순서
1. 기존 DB와 프로젝트를 백업합니다. 작업 중인 사용자는 저장 후 종료합니다.
2. 기존 AxPlatform DB에서 db/manual/13_V006__workbook_formula_capacity.sql을 실행합니다.
   ap_sheet.content_json / previous_json을 LONGTEXT로 확장하고 V006 기록을 남깁니다.
   데이터 삭제·DB 재생성·개인 파일/저장 경로 변경은 하지 않습니다.
   SQL 마지막 조회에서 두 열이 longtext인지, V006이 있는지 확인합니다.
   max_allowed_packet이 64MB보다 작으면 SQL에 기재한 설정을 DB 서버에 적용합니다.
   전역 패킷 설정을 바꾼 뒤에는 앱을 재시작해 새 DB 연결을 사용합니다.
3. 압축 안 파일을 pom.xml이 있는 프로젝트 루트에 같은 경로로 덮어씁니다.
   기존 config/application-private.yml과 dev/test 개인 설정은 그대로 유지합니다.
   이 패치에 개인 비밀번호/API 키를 넣지 않았습니다. 삭제할 기존 파일은 없습니다.
4. Eclipse: Refresh → Maven > Update Project → Project > Clean → 실행.
   Java 17 이상이 필요합니다. pom.xml에 Apache POI 6.0.0 계산 의존성을 추가했습니다.
   첨부 파일 규모를 다룰 때 Run Configurations > Arguments > VM arguments에
   -Xmx2g 를 권장합니다. 이미 -Xmx가 있으면 중복하지 말고 기존 값을 조정합니다.
5. 브라우저를 강력 새로고침합니다. 화면 리소스 버전은 0.8.0입니다.

처음 확인할 흐름
엑셀 가져오기 → 시트별 미리보기 → 수식 검토의 셀 주소 클릭 → 해당 위치 확인 →
필요할 때만 '현재 기준 임시 처리 검토' → 기본정보 → 내용 확인 → 편집 → 전체 시트 저장 → 데이터 보기.
편집 화면에서도 셀 주소 이동, fx 값·수식 입력, 문제 수식 검토·원본 복원이 가능합니다.

중요: v0.7.0에서 값만 저장했던 표에는 원래 수식이 들어 있지 않습니다.
원본 XLSX를 다시 가져와야 수식을 복구할 수 있습니다. 원본을 새 프로젝트에서 가져와
확인하는 방식이 안전합니다. 수식을 알 수 없는 값만 보고 수식을 만들어 넣지 않습니다.
