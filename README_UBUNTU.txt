AxPlatform v0.3.0 / Ubuntu 이관 메모

이번 전달은 기존 로컬 프로젝트를 이어가는 소스 업데이트입니다. 운영 배포·Eclipse 구동·공개 HTTPS 환경 검증을 했다는 뜻은 아닙니다.
Java17 / 단일 Maven 프로젝트이며 JAR는 target/AxPlatform.jar입니다. 별도 npm/프런트 서버는 요구하지 않습니다.
배포 폴더 config/application-private.yml 한 파일에서 MariaDB 접속·public-base-url·저장 폴더·OpenAI 키를 설정합니다.
모델 기본값은 gpt-6-astra/high입니다. 키는 JAR/JS/공유 ZIP에 넣지 않습니다.
프로세스 작업 폴더는 pom.xml 또는 JAR와 함께 config/가 보이는 배포 루트여야 합니다.

기존 V001/V002 DB는 앱 중지 → V003 → 07 확인 후 v0.3.0을 시작합니다.
신규 DB는 V001 → V002 → V003 순서입니다. db/manual/README_SQL_ORDER.txt를 따르세요.
DB와 서버 첨부 폴더는 함께 이관·백업해야 합니다. 개인 설정파일만 옮기면 자료까지 이동하지는 않습니다.

현재 127.0.0.1 바인딩은 로컬용입니다. 공개 HTTPS 주소·프록시·Secure 쿠키·공급자 콜백은 운영 환경에 맞게 별도 검수합니다.
Java main은 UTC 기준이며 UI는 표시 시 브라우저 로컬 시간으로 변환합니다. AI 일일 제한도 UTC 날짜 기준입니다.
긴 AI 작업은 원래 사용자 세션 종료·시간 초과·서버 재시작으로 중단될 수 있고 유료 요청을 자동 재시도하지 않습니다.
예약 작업을 새 서버가 무조건 이어 실행한다고 가정하지 마세요. 저장된 작업 기록과 오류로 다시 확인합니다.

운영용 서비스/방화벽/비밀 저장소/백업·복구/비용·보존 정책은 별도 운영 준비 항목입니다. 자동 설치·배포 스크립트는 포함하지 않았습니다.
실제 검수 범위는 docs/TEST_REPORT.txt를 확인하세요.
