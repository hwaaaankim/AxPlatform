실행하지 못한 검증
- 실제 Chromium 실행이 환경의 socket 권한 제한으로 차단되어 브라우저 캡처 기반의
  육안·터치·운영체제 파일 선택창/키보드 접근성 검수는 완료하지 못했습니다.
- 현재 실행 환경에서 Maven 테스트 의존성 캐시가 없어 Spring/H2 통합 테스트를
  이번 v0.4.2에 대해 재실행하지 못했습니다. 실제 Spring TemplateEngine으로
  템플릿을 렌더링한 결과와 프런트엔드 테스트를 근거로 합니다.
- 원격 MariaDB, 실제 등록 파일 영구 저장, 실제 OpenAI·인증·결제 서비스는 미검수입니다.

적용 후 확인할 항목
- 파일 3개 선택 → 1개 × → 다른 파일 추가 → 등록 → 등록 목록 확인.
- 선택 목록 전체 비우기와 등록 목록 삭제가 서로 다른 범위임을 확인.
- 검색한 등록 파일만 표시 전체 삭제 → 삭제한 파일 보기 → 복원.
- 엑셀 CSV 1개 선택 → 미리보기 → 초기화 → 기존 편집 표가 유지되는지 확인.
- 엑셀 날짜 열에서 달력 적용/취소/직접 입력, 관리자 만료일 유지/변경/비우기.
- 320/375px 및 데스크톱에서 긴 파일명·여러 버튼·달력·메뉴가 잘리지 않는지 확인.
- 키보드 Tab/Shift+Tab, 달력 F4/Alt+↓/화살표/Escape, 필수 날짜 안내 확인.
- 실제 사용자 권한·세션 만료·409 동시 변경·서버 업로드 거부 시 메시지와 데이터 보존 확인.
