AxPlatform 0.8.0 적용 안내

0.7.0 원본에 UPDATE_v0.8.0.txt 순서대로 적용합니다. SQL은 앱이 자동 실행하지 않습니다.
13번 SQL의 V006은 DB 변경 번호이며, 앱 버전 0.6과는 별개입니다.
현재/이전 통합문서 JSON 두 열을 LONGTEXT로 확장합니다. 기존 자료는 유지합니다.
첨부 엑셀을 수식 포함 편집 JSON으로 가져오면 약 16.82MB입니다.
기존 MEDIUMTEXT의 16,777,215바이트를 넘어 실제 저장 확장이 필요합니다.
앱의 최종 JSON 한도는 UTF-8 32MB이며, 14MB 초과 저장에는 V006 적용을 확인합니다.
MariaDB/MySQL 연결의 패킷 한도가 저장 내용보다 작으면 구체적인 설정 안내를 반환합니다.

원본 수식과 입력을 보존하는 방법
- Excel A1 주소 기준으로 셀 수식을 보관합니다. 제목 행은 1행, 데이터 첫 행은 2행입니다.
- 공유 수식은 상대·절대 참조를 구분해 각 셀의 수식으로 복원합니다.
- 결과가 빈 수식 셀도 가져오기 범위에 포함합니다.
- 날짜의 원래 숫자, 숫자처럼 보이는 문자열 등 계산에 필요한 원본 형식을 보관합니다.
- 값 수정 후 자동 계산, 수동 다시 계산, 저장 시 서버 계산을 수행합니다.
- 셀 fx 입력에 =SUM(B2:C2)처럼 입력하거나, AI 검토에서 셀 수식을 제안받을 수 있습니다.
- 수식 계산 자체는 OpenAI를 호출하지 않습니다. AI 대화 요청은 기존 동의/사용량 정책을 따릅니다.
- 저장한 계산 결과를 데이터 보기와 대시보드 집계에 사용합니다.

문제 셀과 일괄 임시 처리
- 미리보기와 편집 양쪽에 전체 시트의 문제 셀 목록이 있습니다. 25개씩 탐색합니다.
- 주소를 누르면 해당 시트와 페이지로 이동하고 셀을 강조합니다. 편집에서는 검색·정렬 보기를
  초기화해 원본 셀을 찾습니다. 스크롤로 수만 행을 찾아갈 필요가 없습니다.
- 오류 수식, 지원 밖 참조/함수, 원본 입력 오류, 임시 값의 영향을 받는 결과를 구분합니다.
- 임시 처리 버튼은 먼저 범위·건수·셀별 처리 방식을 보여 줍니다.
- 지원하지 않는 수식에 오류가 아닌 마지막 계산값이 있으면 그 값을 임시로 사용합니다.
- 유효한 결과가 없거나 실제 계산 오류가 있으면 원본 수식을 별도로 보관하고 결과 칸만 비웁니다.
- 원인이 되는 셀을 참조하는 다른 수식은 유지합니다. 필요한 입력을 다시 넣으면 계산을 이어갑니다.
- SUM 결과가 문제라고 합계 범위 안의 원본 입력을 삭제하지 않습니다. 문제 결과 자리만 검토합니다.
- 수식 입력 이전의 값이 원본에 없으면 복원할 수 없습니다. 빈칸은 '과거 값 복원'을 뜻하지 않습니다.
- 보관한 수식은 프로젝트에서 다시 복원하거나 새로운 수식으로 교체할 수 있습니다.
- 임시 숫자·오류 또는 그 영향을 받는 결과는 그래프 숫자로 확정하지 않고 집계에서 제외하며
  제외한 행 수를 표시합니다. 실제 값을 입력하면 다시 집계할 수 있습니다.
- 임시 처리/복원도 전체 시트 저장 전에는 편집 초안입니다. 저장 후 기존 한 단계 되돌리기를 지원합니다.
- 내려받은 XLSX는 현재 적용된 값·활성 수식을 담습니다. 임시 중지 수식의 복원 이력은
  AxPlatform 프로젝트 DB에 보관합니다. XLSX만으로 프로젝트의 임시 처리 이력을 복원하지 않습니다.

구조 변경과 범위
- 행 삭제, 열 이동·삭제, 시트 이름 변경·삭제 시 원본 수식의 참조를 함께 조정합니다.
- 삭제된 직접 참조는 #REF!로 표시합니다. 행 삭제 시 SUM 범위는 남은 범위로 줄입니다.
- 한 범위가 열 이동으로 떨어진 영역이 되거나 안전하게 해석할 수 없는 참조이면 변경을 중단합니다.
  잘못된 셀을 조용히 참조하도록 바꾸지 않습니다.
- 다른 시트를 참조하는 파일은 관련 시트를 함께 가져와야 합니다. 기존 시트와 이름이 겹치면
  새 프로젝트를 쓰거나 기존 시트 이름을 바꿔 충돌을 해결하도록 안내합니다.
- AI 범위 편집은 지정 행의 값·셀 수식만 수정합니다. 원본 Excel 주소 기준 수식을 사용합니다.
  작은 표 전체 제안은 기존 순서를 유지하며 끝에 행·열 추가가 가능합니다.

지원 한도와 제한
- 프로젝트 20시트, 시트 100열·50,000 데이터행·100만 셀, 프로젝트 합계 200만 셀.
- 계산 수식 합계 20만 셀, 수식 문자열 8,192자/셀, 최종 프로젝트 JSON 32MB.
- 파일 10MB, 압축 해제 합계 128MB/개별 XML 64MB. 무제한 압축 해제는 하지 않습니다.
- 동시 계산 2개, 계산 결과 평가 시간 30초 기준. 큰/반복 참조 범위는 별도 제한합니다.
- 모든 Excel 함수를 구현한 엔진은 아닙니다. 이름 정의·외부 파일·구조화 참조·배열/동적 배열,
  확장 함수, 일부 복잡한 참조는 수식과 사유를 보관하고 임시 처리 또는 직접 수정을 안내합니다.
- 서로 다른 1900/1904 날짜 체계 시트 사이 참조와 1904 날짜 함수는 지원 밖으로 안내합니다. 날짜 일련번호/표시 메타데이터는 보존합니다.
- 차트·매크로·피벗·외부 연결을 원본 Excel 그대로 실행하거나 편집하지 않습니다.
  일반 셀 데이터로 새 그래프를 만드는 기존 데이터 보기 흐름을 사용합니다.
- 원본 XLSX 파일 자체는 변경하지 않습니다. 지원하지 않는 Excel 객체의 완전한 왕복 편집은
  원본 Excel을 사용해야 합니다.

기존 설정·보안
- 공용 DB + 기기별 파일 저장, 로컬 파일 없음/교체 처리, 멤버 권한·버전 충돌 검사를 유지합니다.
- 수식 변경은 별도 formula.update 권한으로 검사하며 AI 적용도 같은 검사를 통과해야 합니다.
- 외부 파일이나 네트워크 함수를 수식 계산에서 호출하지 않습니다.
- 개인 설정과 실제 DB·API 자격증명은 패치에 포함하지 않습니다.
