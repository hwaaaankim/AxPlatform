AxPlatform 0.9.0 개발 반영 범위 / 2026-10-25

이번 요청의 기준
가공된 통합문서 저장을 1차 완료로 삼고, 같은 저장 데이터를 기준으로 여러 조회·계산·보고서·
다운로드를 반복하는 구조. 저장 보기 한 개를 만들기 위한 폼을 기본 화면으로 삼지 않습니다.

실제 구현
- 저장 직후/다시 열기: 원본 테이블 기본 표시, 업무 목록의 실제 표 저장 여부·진입 링크 수정.
- 공통 38px 입력/버튼 높이, 압축한 저장 상태/상단 도구, 220px 시트 선택, 선택 도구 패널,
  표 내부 가로/세로 스크롤, 좁은 화면 재배치. 그래프 선택 역시 줄바꿈·너비를 제한합니다.
- 서버 표 조회/AND 필터/표시 열/다중 정렬/다중 그룹·집계와 정확한 원본 행 이동.
- 가능한 그래프 제안, 여러 저장 보기 탭, 실제 데이터 기반 예시.
- 현재 보기 전체 XLSX·CSV, 원본 전체 XLSX 구분.
- 수식 계산 열 사전 검토/오류 승인/실제 저장, 대화 편집 연결.

구조
DataReport: 원본 → 조건 적용 → 테이블 또는 집계 → 정렬 → 페이지/그래프. CSV/XLSX도 같은 결과 사용.
CalculatedColumn: 수식 템플릿을 원본 주소에 맞춰 추가하고 기존 WorkbookCalculation으로 계산.
DataCenterService/Controller: 기존 권한·사업 범위·버전·세션·저장 서비스와 연결.
SheetViewService: 기존 보기와 AX_DATA_VIEW_1 호환, 여러 보기 저장/수정/삭제.
DraftService: 실제 ap_sheet 저장 여부를 업무 목록에 반환.
sheet-analysis/data-center-tools: 즉시 표 표시, 요청한 패널 하나만 펼치기, 안전한 DOM 렌더링.
기존 편집기·파일 관리·여러 시트·AI 검토/적용·수식 복원 경로를 재사용합니다.

이전 요구와 연결
0.7 순차 입력/미리보기/뒤로가기 → 0.8 원본 수식 보존·계산·오류 위치/임시 처리 →
0.9 저장 데이터 센터/다중 보기/계산 열/보고서·내보내기로 이어집니다.
0.5 파일/활동·토큰 기록과 0.6.1 공유 DB/기기별 원본 보관 정책을 유지합니다.

완료로 표시하지 않는 범위
- 모든 Excel 함수/피벗/매크로/차트 객체의 완전 호환, 여러 프로젝트 사이 조인/피벗 열 전개,
  저장 보기 여러 개를 한 화면에 배치하는 위젯 빌더, 그래프 PNG/PDF 내보내기, 보고서 예약 발송.
- Word/HWP/PPT/CRM/일정/앱의 최종 편집·실행 엔진과 결제/고객 유치 운영 전체.
- 실제 유료 AI 요청/운영 MariaDB 부하/실제 브라우저 픽셀 검수.
이를 이번 구현과 혼동하지 않습니다. 지원 한도와 실제 검증은 V090_APPLY/VERIFICATION을 따릅니다.
