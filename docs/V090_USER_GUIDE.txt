AxPlatform 데이터 센터 사용 예시

저장 후에는 먼저 데이터가 보입니다.
편집에서 '전체 시트 저장'을 완료하면 데이터 센터 원본 테이블이 열립니다.
다음 접속에는 업무 목록에서 '데이터 센터 열기'. '현재 데이터 시트'는 이 프로젝트에
저장한 여러 시트 중 지금 조회할 시트를 고르는 버튼입니다. 원본을 교체하는 선택이 아닙니다.
보기 설정은 필요할 때만 오른쪽에 나타납니다. 좁은 화면에서는 표 위로 이동합니다.

예시 A — 특정 거래처의 원료투입만 보기
1. 현재 데이터 시트: 원료투입.
2. 조회 조건 → + AND 조건 → 조건 열 '거래처' → 같음 → 실제 거래처명 입력.
3. 필요하면 + AND 조건 → '중량(kg)' → 이상 → 최소 중량 입력 → 조건 적용.
4. 표의 중량 열 제목을 누르면 오름/내림차순 전환. '정렬·표시 열'에서는 여러 정렬 기준과
   표시할 열을 선택할 수 있습니다.
5. 현재 보기 저장 → '거래처별 원료 확인'처럼 이름 지정. 위 탭에서 다시 열 수 있습니다.
화면 아래 '이 데이터로 무엇을 볼 수 있나요?'에는 실제 열 이름과 실제 존재하는 값으로
만든 예시가 나옵니다. 해당 예시는 원본 데이터를 수정하지 않습니다.

예시 B — 월별 원료 중량과 건수를 함께 보기
1. 원본 테이블 → 보고서 만들기.
2. X축 묶음 기준 '월' 선택.
3. Y축 집계값 '중량(kg)' / '합계'. '+ 집계값'을 눌러 '행 개수'도 추가.
4. 보고서 확인. 먼저 집계 표가 표시되며 막대 또는 꺾은선으로 전환할 수 있습니다.
5. 월 순서가 필요하면 정렬·표시 열에서 월 오름차순을 설정합니다.
6. '월별 원료 중량·건수'로 현재 보기 저장. 건수와 중량은 단위가 다르므로 정확한 수치는
   표를 기준으로 확인하고, 각각 별도 그래프로 저장할 수도 있습니다.
그래프는 선택한 20/50/100/200항목을 보여 주고 나머지 개수를 명시합니다.
전체 결과는 표의 다음 페이지 또는 다운로드에서 확인합니다.

예시 C — 거래처와 원료명 조합별 집계
보고서 만들기 → X축에 거래처와 원료명 모두 선택 → Y축에 중량(kg) 합계/평균 추가.
같은 거래처라도 원료명이 다르면 별도 행으로 나옵니다. 여러 X 기준은 막대/표로 볼 수 있습니다.
원형 그래프는 조건에 맞을 때만 활성화되고, 비활성 버튼에 적용 조건을 표시합니다.

예시 D — 단가 × 중량으로 실제 계산 열 만들기
1. 원본 테이블 → 계산 열 추가 → 새 열 이름 '계산 금액'.
2. 계산 방법 '두 열 곱하기' → 단가 / 중량(kg) 선택.
3. 전체 행 또는 현재 AND 조건에 맞는 행을 선택합니다.
4. 계산 미리보기 → 계산 대상 건수, 첫 10행 결과, 전체 오류 건수 확인.
5. 검토한 계산 열 저장 → 원본 표 오른쪽에 수식 열이 생깁니다.
숫자가 아닌 단가나 기존 오류가 있으면 결과 오류를 확인하고 원본 편집에서 수정하세요.
임의의 가격/금액을 추정해서 넣지 않습니다. 저장 후 원본 값 변경 시 수식을 다시 계산합니다.

예시 E — 다른 시트에서 코드에 맞는 값 찾기
계산 열 추가 → VLOOKUP → 현재 시트의 코드 열 → 찾아볼 시트 → 그 시트의 키 열/반환 열.
정확히 같은 키의 첫 일치를 사용합니다. 없는 키는 #N/A입니다.
반환 열이 키 열보다 왼쪽이면 INDEX/MATCH로 바꿉니다. '미리보기' 후 저장합니다.
샘플에 맞지 않는 계산은 직접 수식 입력 또는 '대화로 데이터·수식 편집'으로 요청합니다.

예시 F — 서로 다른 납품용 파일 만들기
표에서 거래처 조건과 필요한 열만 선택 → '거래처 제공용' 보기 저장 → 다운로드 → 현재 보기 XLSX.
다른 보기에서는 월별 합계 → '내부 월간 집계' 보기 저장 → 현재 보기 CSV.
파일에는 조건에 맞는 전체 결과가 들어갑니다. 원본 전체 XLSX는 여러 시트와 수식을 함께 받는 별도 버튼입니다.
필터와 보기 삭제는 원본 삭제가 아닙니다. 원본 셀은 '원본 편집' 또는 각 행의 '행 편집'에서 수정합니다.
