범위를 구분할 사항
- 실제 운영 DB에 접속하거나 13번 SQL을 대신 실행하지 않았습니다. SQL은 사용자가 적용합니다.
- 실제 유료 OpenAI 요청은 실행하지 않았습니다. AI 제안의 검증·적용·권한/멱등성 경로는
  로컬 테스트 제안으로 확인했습니다.
- 브라우저 엔진 설치가 제공되지 않아 실제 Chrome/Safari의 픽셀·스크롤 실기기 검사는
  수행하지 못했습니다. DOM 동작과 서버 렌더링을 검사한 결과이며 이를 시각 검수로 표기하지 않습니다.
- MariaDB의 DDL/패킷/동시 운영 부하 검수는 사용자 환경에서 수행해야 합니다.
- 사용자 엑셀·테스트 출력·개인 키·DB 백업·target·node_modules는 배포 ZIP에서 제외했습니다.

메모리 참고
원본 읽기·계산·검증 도구는 -Xmx768m에서 성공했습니다(측정 약 15.5초, 프로세스 최대 RSS 약 1.0GB).
이는 테스트 환경의 한 번 측정값이며 운영 성능 보장이 아닙니다.
Spring 앱과 큰 문서를 함께 사용할 로컬 실행은 -Xmx2g를 권장합니다.
