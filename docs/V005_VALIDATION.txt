실행 환경과 재현
- Java 네트워크 제약으로 이 환경에서 Maven의 의존성 다운로드와 mvn test 목표 실행은 완료하지 못했습니다.
  런타임/테스트 의존성을 확보한 뒤 JavaCompiler API(--release 17, -parameters)와 JUnit Console로 전체 소스와 테스트를 실행했습니다.
- 일반 개발 환경에서는 pom.xml 기준 mvn test 또는 Eclipse Maven test를 실행하세요.
- DOM/추가 통합 검사의 재현 방법은 qa/README.txt입니다. 테스트 데이터와 임시 디렉터리만 사용했습니다.
- 수정 전 프런트 테스트 fixture가 새 selected API의 context.currentInput을 제공하지 않아 실패한 부분은 실제 호출 계약에 맞게 갱신 후 재실행하여 통과했습니다.

- 실제 브라우저의 픽셀 배치·반응형 터치·키보드 IME 검수. DOM 검사를 브라우저 시각 검수로 표시하지 않습니다.
- 실제 OpenAI 키로 유료 호출, 모델 프로젝트 권한/청구서 대조, 외부 로그인·SMTP·문자·결제.
