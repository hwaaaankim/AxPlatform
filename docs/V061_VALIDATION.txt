방법
이 실행 환경의 기존 Maven 의존성 JAR 캐시와 JavaCompiler(--release 17 -parameters), JUnit Console를 사용했습니다.
mvn clean package 실행 성공으로 주장하지 않습니다. 일반 개발 PC에서는 mvn test 또는 Eclipse Maven test로 실행할 수 있습니다.
Node/happy-dom은 테스트 전용이며 앱 실행에 필요하지 않습니다.
