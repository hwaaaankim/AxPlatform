AxPlatform v0.3.0 / 서버 연동 설정

OpenAI
- 정확한 위치: 프로젝트 루트/config/application-private.yml → ax.integrations.openai.
- 기존 enabled:false는 true로 바꾸고 api-key에 본인 프로젝트 키를 입력합니다.
- 같은 YAML 파일에 ax/openai 블록을 중복 추가하지 말고 기존 항목을 수정하세요.
- 모델 기본값 gpt-6-astra, reasoning-effort high. 출력 토큰/대기/도구/자료/작업 한도는
  공통 src/main/resources/application.yml과 개인 설정 예제에 비밀 아닌 값까지 작성되어 있습니다.
- config/application-private.example.yml은 값이 비어 있는 작성 양식이며 실제 private 파일로 덮어쓰지 않습니다.
- 키 변경 후 앱을 다시 시작합니다. UI의 설정 조회에는 키 대신 사용 가능 여부·모델·제한만 표시합니다.
- API 모델 접근 권한·과금·네트워크가 필요합니다. 실제 키로 실호출·사진 품질은 이번 환경에서 미검증입니다.
- 미입력/비활성/공급자 실패 때 가짜 결과를 만들지 않고 입력을 보존합니다. 직접 표 편집·저장·다운로드는 AI 없이 동작합니다.
- 자료는 본인 초안에 연결한 PNG/JPG/TXT에서 최대3개·총6MB를 명시 선택합니다. 암호·OTP·API 키를 업무 프롬프트에 넣지 마세요.
- 모델은 제안하고 서버가 허용 도구/현재 범위·권한/형식/버전을 검사하며 최종 반영은 사용자가 선택합니다.
- 공개 MCP 프로토콜 서버 설정은 없습니다. 외부 클라이언트 연결을 받는 대신 Java 내부의 허용 도구 계층을 사용합니다.

기존 인증/가입
- SMTP 메일, SOLAPI 문자, Google OIDC, 카카오·네이버 OAuth2의 등록/입력 위치는 P1_INTEGRATIONS.txt.
- 현재 관리자 로그인과 직접 표 편집은 이 서비스들의 가입/실키 없이 시험할 수 있습니다.
- 실제 공개 회원가입을 켜려면 인증용 OTP 비밀값·SMTP/SMS 연결/수신과 공급자 콜백을 먼저 검수합니다.
- 초기 관리자 admin/12345 생성 규칙과 기존 암호 보존은 그대로입니다.

후속
Cafe24/알림톡·Toss·고객별 Gmail·자동 발송·문서 편집/HWP 엔진·공개 MCP는 현재 연결 완료가 아닙니다.
정확한 후속 범위는 PENDING.txt, 현재 검사 결과는 TEST_REPORT.txt를 확인하세요.
