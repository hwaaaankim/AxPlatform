AxPlatform v0.4.2 전체 페이지 점검표

점검 방법
템플릿 전체와 동적 JS 폼을 검토했습니다. 27개 템플릿 변형을 Thymeleaf로 렌더링하고,
공통 레이아웃 구조와 주요 UI 이벤트를 검사했습니다. 실제 브라우저 화면 캡처·터치
검수, 실서비스 DB/외부 서비스 통합검수와는 구분합니다.

현재 개발 단계
- v0.4.1의 헤더 중복/여백/메뉴 수정 위에 파일·날짜·선택·초기화 상세 동작을 추가한 v0.4.2입니다.
- 엑셀은 기존의 수동 표 편집, XLSX/CSV, 계산식, 저장·분석 흐름을 사용합니다.
- 워드/한글/PPT/CRM/일정/앱 메뉴는 현재 소스에서 요구사항 정리와 AI 제안 검토 단계입니다.
  이번 개선이 DOCX/HWP/PPT 생성 엔진, CRM 실업무 엔진, 일정 알림, 앱 배포 기능을
  완성한 것은 아닙니다. 화면에서도 기존 '준비 중' 표시를 유지합니다.
- 가입·외부 AI·메일·문자·결제·외부 편집기 연결은 실제 설정과 별도 통합검수가 필요합니다.
- 따라서 이 패치의 검증 결과를 전체 상품의 유료 운영 승인이나 모든 엔진 완성으로
  해석하지 않도록, 개선 범위와 남은 기능 범위를 분리해 기록합니다.
