AxPlatform 0.9.0 검증 기록 / 2026-10-25

서버
- Java 17 전체 소스 100개, 테스트 소스 19개 컴파일 성공.
- 전체 JUnit 134개 실행/134개 성공/실패 0/건너뛰기 0.
- 실제 Spring/H2 통합: 표 저장·목록 플래그·읽기 권한, 사업 범위 격리, CSRF,
  여러 보기 저장/수정/삭제·구버전 호환, 원본 유지, 계산 열 미리보기/저장/버전 충돌,
  수식 권한·오류 명시 승인, 전체 결과 CSV/XLSX·다운로드 권한·내용 검증.
- v0.8 실제 큰 통합문서의 DB 저장/재조회/다운로드/수정·되돌리기 회귀 포함.
- 외부 API 오류 검사 로그는 테스트 응답이며 실제 OpenAI 요청을 보낸 것이 아닙니다.

첨부 데이터 기반 검사
- 기존 v0.8 검증으로 생성한 수식 포함 통합문서 JSON을 새 DataReport로 읽었습니다.
- 원료투입: 24,987행/15열, 월 기준 중량(kg) 합계·건수, 139개 그룹.
- 원단입출고: 16,167행/21열, 월 기준 입고 합계·건수, 134개 그룹.
- 원본 테이블 전체 행 수·마지막 행 보존 확인.
- 각 시트 숫자 열을 따로 순회한 합계와 보고서 집계 합계가 일치했습니다.
- 사용자 파일/변환 데이터는 읽기 전용 검사에만 사용하고 배포물에 포함하지 않았습니다.

DOM/리소스
- 데이터 센터 17개 동작: 즉시 테이블, 원본 행 이동, AND, 표시 열/정렬, 다중 X/Y,
  그래프와 표 동시 확인, 여러 보기 저장/열기, 실제 열 수식 생성, 미리보기 무변경,
  설정 변경 시 미리보기 무효화, 확정 저장, AI 요청 준비, 다운로드 범위 안내, 실제 값 예시,
  새로고침 시 다른 기기에서 변경된 시트/열도 다시 불러오기.
- 목록 진입 검사: 분석 권한 없는 표 읽기 사용자도 저장 표 데이터 센터로 진입,
  실제 저장 배지/finish 경로/미저장 작업 구분/저장 건수 확인.
- 수식 UI 회귀 13개, 순차 흐름 14개, 다중 시트·사진/AI 회귀 14개 통과.
- 회원/관리자 포함 24페이지 공통 렌더·리소스 계약 통과.
- JavaScript 36모듈 문법 검사 통과.
- DOM 검사는 Happy DOM + 로컬 모의 HTTP 응답이며 실제 브라우저 E2E와 구분합니다.

미실행
- 실제 운영 MariaDB와 개인 API 키로 연결하지 않았습니다. 운영 데이터/설정 변경 없음.
- 실제 유료 AI 요청, 동시 사용자 부하 시험, Chrome/Safari 실제 픽셀/기기 스크롤 검수는 미실행.
  Chromium 설치 다운로드가 완료되지 않아 브라우저 화면 검수를 수행할 수 없었습니다.
  서버 렌더/DOM/반응형 CSS 검사 결과를 실브라우저 시각 검수로 표기하지 않습니다.
- Maven 최종 package 명령은 이번 실행 결과가 아닙니다. 로컬에서 확보한 pom 의존성으로
  Java 컴파일과 JUnit을 실행했습니다. Eclipse/Maven 적용 순서는 UPDATE 파일에 기재했습니다.
