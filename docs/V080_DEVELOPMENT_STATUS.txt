AxPlatform 0.8.0 개발 반영 범위

이번 요청: 원본 수식을 지우지 않고 자동 계산 → 직접/대화 수식 추가 → 계산값 분석.
추가 요청: 문제 셀 클릭 이동 → 사유별 검토 → 흐름에 맞는 임시 처리 → 추후 입력/복원.

반영한 공통 구조
ExcelCells: 셀 수식·원본 값 형식·문제·임시 중지 원본 수식을 제한된 JSON으로 관리.
WorkbookCalculation: 실제 계산, 순환/참조 오류 분류, 문제 원인과 종속 수식 분리,
원본 보관 후 임시 처리·복원. 계산 자원 한도와 외부 연동 금지.
WorkbookStructure: 원본 주소와 안정적인 행/열 ID를 연결해 구조 변경 시 참조 보정.
SheetImport / XlsxWriter: 기존 스트리밍 XLSX 읽기·쓰기에 수식 보존을 연결.
SheetService: 권한·버전·자료 연결 검사 후 서버에서 계산하여 저장.
SheetAnalysis: 미확정 값의 집계 제외와 제외 수 보고.
AiSheetScope / ProposalRules: =로 시작하는 검토 수식 제안, 범위 밖 데이터 보존,
반복 검증·중복 적용 방지와 기존 권한을 유지.
formula-review.js: 미리보기/편집이 공유하는 문제 목록·주소 이동·임시 처리 검토.
sheet-editor.js: fx 입력, 자동 계산, 오래된 계산 응답이 새 입력을 덮지 않도록 버전 확인.

이전 단계 유지
0.7.0의 시작 → 자료 준비 → 기본정보 → 내용 확인 → 편집 → 저장/데이터 보기,
이전 단계 이동, 재편집 단축 버튼, 여러 시트·사진별 시트·업로드 미리보기,
페이징·검색·정렬·파일 리스트/추가/삭제 UI와 공통 레이아웃을 이어 사용합니다.
0.6.1의 기기별 파일 상태 처리와 0.5의 파일 관리·활동/AI 사용량 기록을 변경하지 않습니다.

구분해야 할 완료 범위
이번 패치는 Excel/데이터 경로의 구현과 검증입니다. Word/HWP/PPT/CRM/일정/앱의
최종 문서 편집기, 업무 시스템, 결제/고객 모집까지 완성되었다는 의미가 아닙니다.
운영 DB 적용과 실제 유료 AI 연결은 사용자 환경에서 별도 실행해야 합니다.
프런트 API·서버 검증·권한 흐름을 함께 수정했으며 화면 모형만 제공하는 패치는 아닙니다.
