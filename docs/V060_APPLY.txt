AxPlatform 0.6.0 — 다중 시트 수정본 적용 안내
2026-10-21 / 적용 기준: 0.5.0 전체 소스 + 0.5.1 패치가 반영된 프로젝트

이번 변경
1. 편집 화면에 시트 탭, 시트 추가, 이름 변경, 복제, 순서 이동, 삭제를 추가했습니다.
   직접 입력 / AI·대화 / 엑셀·CSV 가져오기 / 사진으로 만들기로 시트를 추가합니다.
2. 사진 한 장으로 새 프로젝트를 만들 수 있고, 여러 장을 현재 프로젝트의 별도 시트로 준비할 수 있습니다.
   등록 사진 목록에서 개별 × 또는 전체 해제로 시트 생성 대상을 조정합니다. 원본 파일은 삭제하지 않습니다.
3. 사진별 AI 결과를 성공·추가 확인·실패·미요청으로 구분합니다.
   성공한 시트만 골라 한 번에 적용합니다. 읽기 실패 시 이유·영향받는 위치·재촬영/원본 수정 안내를 제공합니다.
   판독 내용은 AI의 판단이므로 원본과 숫자·날짜를 대조한 뒤 적용해야 합니다.
4. XLSX의 모든 시트를 검사하고 정상 시트를 선택해 추가합니다. 기존 시트는 보존합니다.
   숨김 시트는 표시하되 기본 선택에서 제외합니다. 빈 시트도 추가할 수 있습니다.
5. 전체 시트 저장·되돌리기·XLSX 다운로드·빈 양식 재사용을 연결했습니다.
   분석은 시트를 먼저 고르고, 저장한 보기에도 시트 ID를 보관합니다.

사용 순서
새 프로젝트: 엑셀·데이터 → 새 작업 → 사진에서 시작 → 사진 등록 → 사진별 시트로 준비
→ AI 검토에서 대상 사진·시트와 전송 동의 확인 → 검토 요청 → 시트별 결과 대조 → 선택 시트 적용
→ 직접 편집 → 저장하고 데이터 보기.

기존 프로젝트: 표 직접 편집 → + 시트 추가 → 원하는 시작 방법.
AI·대화는 빈 시트를 만든 뒤 AI 탭을 엽니다. 엑셀·사진은 자료 준비로 이동합니다.
엑셀 파일은 1개씩 선택하되 그 안의 여러 시트를 한 번에 가져옵니다.
파일별 미리보기에서 수식·차트·오류 안내를 확인한 뒤 가져올 시트를 선택하세요.

지원 범위와 제한
- 프로젝트 최대 20시트, 시트별 20열 / 데이터 200행, 전체 시트 JSON은 UTF-8 기준 8MB.
- XLSX/CSV 파일 10MB 이하, XLSX 압축 해제 합계 20MB 이하. 첫 행은 열 제목입니다.
- 사진별 AI는 현재 설정 한도 내에서 최대 3장, 합계 6MB입니다. 한 장당 별도 호출·사용량이 발생합니다.
  더 많은 사진을 준비하면 처음 최대 3개만 이번 요청에 선택하고 나머지는 다음 요청 대상으로 남깁니다.
  월 사용 한도·요청 시간·권한 검사는 기존 서버 정책을 따릅니다. 유료 자동 재시도는 없습니다.
- 원본 Excel의 수식은 실행·복원하지 않습니다. 파일에 저장된 계산값을 가져오며 원본 수식 셀 위치를 표시합니다.
  저장된 계산값이 없거나 오류 값이 있으면 해당 시트를 막고 셀 위치와 해결 방법을 안내합니다.
- 차트·그림·도형·원본 서식은 복원하지 않습니다. 셀 데이터가 있으면 값만 가져올 수 있습니다.
  차트 전용 시트/객체만 있고 셀 값이 없는 시트는 원본 데이터 표가 필요하다고 안내합니다.
- 병합 셀은 범위를 표시하고 병합 해제 후 재등록을 안내합니다. XLS/XLSM/암호 파일은 일반 XLSX로 변환해야 합니다.
- 가져온 값은 우선 문자로 보존합니다. 숫자·날짜·단위는 편집에서 확인하세요.
  앱 자체 계산 열은 기존의 열 ID 기반 사칙연산입니다. 임의 Excel 함수·시트 간 참조 수식은 지원하지 않습니다.
- 사진별 한 제안은 선택 시트를 한 번에 적용합니다. 적용하지 않은 시트는 최신 저장본으로 새 검토를 요청합니다.
- 되돌리기는 모든 시트를 포함한 서버 저장본 한 단계입니다. 여러 단계의 전체 버전 이력 기능은 아닙니다.

적용 방법
1. 실행 중인 앱을 종료하고 프로젝트와 DB·원본 자료를 백업합니다.
2. ZIP 안 AxPlatform 폴더의 내용을 기존 pom.xml이 있는 폴더에 덮어씁니다.
   Java, JS, CSS, Thymeleaf 템플릿, pom.xml을 함께 적용하세요. 일부 파일만 적용하면 계약이 맞지 않습니다.
3. 기존 config/application-private.yml, application.yml, dev/test 프로파일 파일은 그대로 유지합니다.
   이 패치는 설정파일·키·DB 접속 정보·D드라이브 저장 경로를 변경하지 않습니다.
4. Eclipse: Refresh → Maven Update Project → Project Clean → 기존 프로파일로 재시작.
   일반 Maven 환경: mvn clean test package. 기존 서버 실행 방법을 그대로 사용하세요.
5. 브라우저에서 Ctrl+F5로 새로고침합니다. 공통 JS/CSS/템플릿 캐시 버전은 0.6.0입니다.
6. 기존 단일 표 열기 → 시트 추가 → 저장 → 다시 열기 → 모든 시트 XLSX 다운로드 순서로 확인하세요.
   실제 사진 AI 검토는 유효한 기존 키와 모델 권한이 연결된 환경에서 사용자가 요청해야 합니다.

DB / SQL / 원본 파일
추가 SQL은 없습니다. 기존 ap_sheet.content_json/previous_json 및 ap_ai_run.request_json/result_json을 사용합니다.
기존 10~12번 SQL을 이번 패치 때문에 재실행하지 마세요.
단일 표 JSON은 읽을 때 호환 처리하고 새 저장부터 통합문서 JSON으로 보관합니다.
0.5.x로 코드를 되돌리면 새 통합문서 JSON을 읽을 수 없습니다. 롤백은 패치 전 DB 백업과 코드를 함께 복구하세요.
원본 파일의 기존 회원·사업·업무·프로젝트·날짜·용도 경로와 용량 계산은 유지합니다.
시트의 원본 연결은 자료 ID를 참조합니다. 시트 삭제는 원본 파일을 지우지 않습니다.
첨부 해제·원본 영구 삭제 후에도 이미 변환·저장된 셀 값은 유지되며, 해당 원본을 AI에 보내려면 다시 연결해야 합니다.
