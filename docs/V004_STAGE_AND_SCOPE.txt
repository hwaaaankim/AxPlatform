AxPlatform 단계·기획·변경 범위 대조 — v0.4.0

판단 근거
- 사용자 첨부 AxPlatform.zip의 실제 Controller/Service/템플릿/JS/SQL.
- 실무개발기획안 및 개발마스터프롬프트 v1.6.2.
- 이번 요청: 전체 디자인·모션 통일, 사이드 메뉴, 페이지별 튜토리얼, 선택에 따른 단계별 노출,
  엑셀 생성→편집→저장→분석→재편집의 실제 연결.

1. 첨부 v0.3.0 상태
P0 설계 문서 기반으로 P1 인증·회원·등급/권한·사업 범위·공통 초안 기반이 구현되어 있었습니다.
P2 중 기본 엑셀 열·행·셀 저장과 XLSX 출력, AI 사진/대화 제안이 추가된 상태였습니다.
V003이라는 DB 번호나 0.3.0이라는 버전은 기획서의 P3(CRM/일정) 완료를 뜻하지 않습니다.
일곱 메뉴 모두 최종 결과 엔진을 갖춘 상태가 아니며, 여섯 후속 업무는 공통 요구사항 초안만 있었습니다.
이 한계를 화면에 충분히 설명하지 않은 채 시작·질문·편집·요약·AI 설정을 길게 나열한 것이 주요 UX 문제였습니다.

2. 이번 단계
P1 화면·탐색·도움말 재구축 + P2 엑셀 사용 흐름/직접 편집/업로드/계산/분석의 증분 구현입니다.
기획서 P2 전체 완료, P3/P4/P5/P6 업무 엔진 구현, P7 실사용 출시 검수 완료를 주장하지 않습니다.
Java 클래스와 테스트의 V004 표기는 DB/릴리스 번호이며 기획 P4 문서 엔진 단계가 아닙니다.

3. 기획 요구와 이번 연결
[기획 3.2~3.4 / GUIDE / UI-TECH]
공통 Thymeleaf 레이아웃, 좌측 탐색, 역할별 이동, 단계형 화면과 URL 복원, 비동기 편집.
사용자가 선택한 단계와 편집 탭만 보여주며 다른 입력은 DOM/초안에 유지합니다.

[기획 3.12~3.17 / EASE / 사용자 튜토리얼 요구]
공통 디자인 토큰, 버튼/입력 높이, 카드·탭·hover·모달·등장 모션, 모션 감소, 모바일 메뉴.
전체 실제 페이지의 도움말 정의, 모달 오버레이·대상 강조·이전/다음·재실행.
튜토리얼은 저장·삭제·업로드 버튼을 자동으로 누르지 않으며 임시 화면 이동만 복구합니다.
자동 숨김은 브라우저 localStorage의 계정·페이지별 설정입니다. 완료/닫기는 세션 동안만 자동 시작을 멈춥니다.

[기획 7.1~7.6 / EXCEL-NAV·CREATE·MANUAL·APPLY]
업무별 오버뷰/필터 목록 → 상세 편집, 네 시작 방법, 작업 중 입력 보존, 저장 후 재편집.
기본 열 구성, 헤더 속성, 행 추가/선택 삭제, 탭 구분 붙여넣기, 방향키/Enter 이동,
열 드래그와 대체 이동 버튼, 서버 한 단계 되돌리기, 현재 초안 취소.
지원 한도는 20열·200행입니다. 자유 셀 배치/전체 Excel 동등 기능은 아닙니다.

[기획 7.7 / EXCEL-FILE]
XLSX·CSV 읽기 전용 미리보기, 워크시트 선택, 열 연결, 추가/교체 범위 확인, 기존 표와 같은 저장 API.
표·초안 두 버전 검사 및 실제 변경 권한 검증을 유지합니다. 동일 저장 요청 재시도는 새 데이터를 다시 추가하지 않습니다.
파일별 장기 import 계획/세대 스냅샷·여러 단계 복구, PDF 추출·대용량 처리는 남았습니다.

[기획 7.8~7.9 / EXCEL-FORMULA]
숫자 계산 열, 안정된 열 ID 참조, 제한 사칙연산, 서버 재계산, AI 동일 스키마, 순환·삭제참조·0나눗셈 차단.
계산 열 편집 별도 권한 및 AI/일반 표 적용 공통 검사를 추가했습니다.
XLSX 계산 열에는 검증된 수식과 캐시값을 기록하고 빈 참조는 Excel에서도 빈 결과로 처리합니다.
복잡한 Excel 함수/범위 수식/날짜 계산/개별 셀 수식/단위 추론은 후속입니다.

[기획 7.10~7.13 / ANALYSIS]
단일 기준 열 또는 전체 데이터의 COUNT/SUM/AVG/MIN/MAX, BigDecimal 집계, 표 버전·빈 값 수 표시,
막대그래프·정확한 숫자 표, 독립 분석 보기 저장/수정/삭제/재조회.
분석은 서버 저장본만 사용하고 저장 전 변경을 자동으로 섞지 않습니다.
전체/필터/고정 행 선택의 범위 모델, 여러 축·기간·차트 종류, 개별 대시보드 위젯 구성은 후속입니다.

[기획 14.4~14.10 / ADMIN·PERM]
기존 회원·정책 검증 흐름 보존. 권한 목록과 등급 칸을 같은 영역에서 조정하고 검토→적용으로 구분.
신규 4개 행동은 기본 미배정. 실제 계산 변경·분석·파일 읽기 권한을 서버에서 검사합니다.

4. 이후 개발 순서
1) P2 잔여: 사진 원본 셀 좌표/검수 이력, 중복 전표, 대용량/PDF, 수식 범위·조건,
   분석 필터·고정 행/근거행, 양식 버전/추천, 복구 이력, 모바일 행 상세와 실제 Excel 재열기.
2) P3: 여러 CRM의 실제 필드·고객·보기/조건, 거래처 공통 ID, 일정·반복·변경범위·알림 예약.
3) P4: Word/HWP/PPT 객체 편집 엔진·정밀 속성·문서 버전·실제 파일 출력/재열기.
4) P5: 고객별 외부 서비스 연결, 발송/자동화, 결제·사용량·원가·재시도/대사.
5) P6: 프로그램 부품/의존성, 실행 가능한 V1/V2 패키지, 실제 실행·이전/복원.
6) P7: 실제 고객 과제, 브라우저/모바일/IME, 외부 실제 수신, 운영 부하·백업복원·보안 검수.

5. 고객 모집 판단
이번 변경은 기능이 연결된 개발 결과이며 전체 기획의 상용 출시 완료본은 아닙니다.
실제 인증 수신·운영 약관/개인정보 고지·과금/사용량 정산·운영 복구와 사용자 검수는 필요합니다.
측정하지 않은 완료율·시간 절감·수익성이나 ‘실무 투입 완벽’이라는 판정을 하지 않습니다.
