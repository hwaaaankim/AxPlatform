AxPlatform v0.3.0 / 현재 설계 결정

보존
- Java17 / Boot4.1.1 / 단일 Maven / Thymeleaf·일반 JS / MariaDB AxPlatform.
- maven-jar-plugin 3.4.2 직접 고정, spring.web.error.*, 개인 파일 config/application-private.yml 하나.
- SQL은 HeidiSQL 수동 실행, 소스는 첫 import 후 덮어쓰기. sql.init=never, ddl-auto=validate.
- V003만 현재 V001/V002 DB에 추가. 관리자/고객/기존 정책/자료/개인 설정을 초기화하지 않음.
- 고객 등급 GUEST/TIER1/TIER2/TIER3의 독립 배정과 FREE/BASIC/PRO/MAX 대응. 신규 행동은 기본 미배정.

AI와 도구
- 서버 Java HttpClient로 Responses API를 호출하고 허용된 네 내부 도구만 연결.
- 공개 MCP 프로토콜/임의 SQL·셸 실행은 이번 범위에서 제공하지 않음.
- 기본 모델 gpt-6-astra, reasoning-effort high. 실제 키는 서버 private 설정에만 기입.
- 기본 16000 출력 토큰, 원격120초/작업300초, 최대6도구라운드, 3자료·총6MB,
  계정 동시2/UTC 하루 시작등록30, worker2. 실패/취소도 등록 횟수에 포함. 자동 유료 재시도 없음.
- 본인 사업·초안에 연결하고 명시 선택한 PNG/JPG/TXT만 전달. 파일 disk_key·경로·비밀키 미전달.
- 제안은 제한된 JSON 구조로 검증하고 확인/추정/질문/경고를 분리. READY는 검수 가능이며 자동 반영 아님.
- 원래 로그인 세션·계정/현재 정책·범위·기준 버전을 도구/추가 호출/결과 저장/반영 경계에서 다시 검사.
- 외부 HTTP 동안 DB 트랜잭션·공통 정책 잠금을 유지하지 않음. 작업 기한/lease가 만료되면 중단 기록.
- AI 생성/반영은 별도 멱등 키. 취소는 비용 환불이나 이미 반영된 결과 되돌리기를 뜻하지 않음.

표와 변경 범위
- ap_sheet JSON은 열 ID/행 ID를 유지하는 기본 표. 20열/200행, 셀2000자·표2MB.
- TEXT/NUMBER/DATE와 단위/폭, 서버 BigDecimal/ISO 날짜 검증. 임의 수식/SQL/JS 실행 없음.
- 직접 편집과 AI는 같은 SheetRules·변경 권한 검사를 통과. 열 구조/행 추가/행 삭제/셀 수정 권한 분리.
- 모든 표 적용/되돌리기는 기준 표·업무 초안 버전 비교. 오류 시 기존 확정 데이터를 보존.
- XLSX는 서버가 OOXML 파일로 생성. 현재 데이터와 빈 입력 양식을 구분. 사용자 문자열은 자동 수식 실행 안 함.
- EXCEL 복제는 열 구조만 복사하고 실제 행과 행 ID는 제외. 다른 사업으로 자동 연결하지 않음.
- 기존 업무 요약(제목/답변/첨부) 저장·취소, 표 적용·되돌리기, AI 제안 취소는 별도 범위.

권한·보존
- ActionRegistry의 구현 연결과 requiredDependencies가 고정 서버 행동을 정의. 카탈로그 이름만 추가해 실행 코드를 만들지 못함.
- 필수 의존 제거는 저장 시 차단하고 추가 의존은 허용. 정상 adminOnly/준비/비활성/보관/미연결은 기본 거부로 처리.
- 관리자도 자기 ADMIN_TEST 자료만 사용. 사용자 지위가 고객 자료 자동 열람 권한을 주지 않음.
- 다운로드 긴 응답은 원래 세션·현재 권한을 재검사. 전송된 바이트는 회수할 수 없음.
- DB/첨부는 완전히 원자적인 저장 장치가 아니므로 운영 백업/복구·정리 정책은 별도 검증.
- 시간은 Java/DB UTC, 브라우저 로컬 표시. 브라우저 복구는 계정/사업/초안 범위의 업무 입력만.

범위 판정
- 실제 OpenAI 실호출·사진 품질·고객 사용성은 미검증. 코드/엔진 검사 결과는 TEST_REPORT.txt와 구분.
- 기본 표와 공통 AI 제안 증분이며 전체 P2 완료가 아님. 후속 최종 업무 엔진·과금·운영 준비는 PENDING.txt 참조.
