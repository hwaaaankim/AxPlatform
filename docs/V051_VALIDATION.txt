실행 방식
Maven 의존성 다운로드가 제한된 환경에서 확보된 런타임/테스트 JAR을 사용했습니다.
JavaCompiler API(--release 17, -parameters)로 컴파일하고 JUnit Console 6.0.3으로 실행했습니다.
이 환경에서 mvn clean package 성공을 확인했다고 주장하지 않습니다.
모든 서버 자동 테스트는 H2 메모리 DB를 사용합니다. 사용자 MariaDB에 연결하지 않았습니다.
일반 개발 환경의 재현 명령은 qa/README.txt에 추가했습니다.

검증 경계
Happy DOM 계산 스타일/이벤트 검사는 실제 Chrome/Edge의 픽셀·터치·IME 검수와 다릅니다.
현재 실행 환경에서는 실제 브라우저 시각 검수를 완료하지 못했습니다.
Windows/Eclipse 빌드, 실제 사용자 서버 배포, 유효한 새 키로 생성 성공/사용량/청구 검증은 미실행입니다.
현재 제공된 키의 인증 실패를 코드만으로 해결했다고 표시하지 않습니다.
0.5.0의 파일시스템 통합 66개 검사는 그 버전의 기록이며 이번 패치에서 새로 실행한 수치에 포함하지 않았습니다.
