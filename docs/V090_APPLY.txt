AxPlatform 0.9.0 적용 및 동작 계약

1. 적용
UPDATE_v0.9.0.txt 순서로 v0.8.0에 덮어씁니다. 신규 SQL/외부 서비스/의존성은 없습니다.
기존 ap_sheet의 저장 통합문서, ap_sheet_view.config_json을 재사용합니다.
이전 단일 집계 보기 형식은 그대로 읽고 새 화면의 보기 설정으로 변환합니다.
새 보기를 저장하면 AX_DATA_VIEW_1 형식으로 기록됩니다. 데이터 원본은 복제하지 않습니다.
큰 통합문서에는 기존 -Xmx2g 실행 설정을 유지하세요.

2. 원본과 보기의 구분
- 데이터 센터의 시작 화면은 저장된 시트의 원본 테이블입니다. 보기 생성은 필수가 아닙니다.
- 목록의 실제 표 저장 여부는 ap_sheet 존재 여부로 판단합니다. 업무 상태가 DRAFT여도
  표를 저장했다면 '데이터 저장됨'과 '데이터 센터 열기'가 표시됩니다.
- 필터/정렬/표시 열/집계/그래프는 조회 정의입니다. 원본 셀 값을 수정하지 않습니다.
- '계산 열 추가'는 원본 시트 오른쪽에 실제 수식 열을 저장합니다. 미리보기는 저장하지 않습니다.
- '원본 편집' 또는 원본 테이블의 '행 편집'은 같은 저장 통합문서의 편집기로 연결됩니다.
- 저장 보기는 다음 조회 시 최신 저장 데이터로 재계산됩니다. 과거 데이터 스냅샷이 아닙니다.
- 저장된 보기에 필요한 시트/열을 원본에서 삭제했다면 명확한 오류를 표시합니다.
  의미가 다른 열을 임의로 연결하지 않으며, 원본 테이블에서 새 보기를 만들 수 있습니다.

3. 조회와 보고서
- 조건 최대 12개, 모두 AND. 같은 열을 중복 선택해 하한/상한을 함께 지정할 수 있습니다.
- 같음/다름/포함/숫자 비교/빈 값 여부. 숫자 비교의 조건 값은 유효한 숫자여야 합니다.
- TABLE: 표시 열 선택, 정렬 우선순위 최대 4개, 100행 페이지 및 페이지 번호 이동.
- REPORT: 묶음 기준(X) 최대 4개, 집계값(Y) 최대 8개. 같은 열의 합계와 평균은 함께 가능하며
  완전히 같은 집계 항목의 중복은 거절합니다. 합계/평균/최소/최대/고유값 수/행 개수 지원.
- X축의 여러 열은 조합별 그룹입니다. 교차표의 가변 열 피벗 기능을 뜻하지 않습니다.
- NUMBER 유형 열은 숫자로, 그 외 열은 문자열 기준으로 정렬합니다. 빈 값은 뒤에 표시합니다.
  날짜·월 문자열은 원본 값의 형식/정렬에 따라 순서가 달라질 수 있습니다.
- 오류·미확정 임시값이 집계 대상이면 제외 건수를 표시합니다. 유효한 숫자가 없는 합계를
  임의의 0으로 채우지 않습니다. 원본 테이블에는 해당 값/오류를 그대로 표시합니다.
- 프로젝트별 저장 보기 최대 20개. 새 보기/선택 보기 덮어쓰기/보기 삭제를 분리했습니다.

4. 그래프와 파일
- 보고서 표는 항상 남고, 가능한 그래프 종류를 함께 제시합니다.
- 막대: 단일·다중 기준과 여러 집계값. 꺾은선: 기준 1개, 결과 2개 이상.
- 원형: 기준 1개/집계 1개, 전체 결과 12항목 이하, 음수 없이 양의 합계일 때.
- 그래프 표시 20/50/100/200항목을 선택합니다. 현재 정렬 순서의 앞 항목이며
  생략 건수를 표시합니다. 나머지는 표 페이지와 전체 다운로드로 확인합니다.
- 기간 추이를 보려면 기간 열 오름차순을 직접 설정합니다. 금액과 중량 등 다른 단위의
  지표는 별도 보기로 나누는 것이 좋습니다. 다중 Y는 지표 여러 개이며 이중 축 배율은 아닙니다.
- 현재 보기 XLSX/CSV는 필터/정렬/표시 열/집계를 적용한 전체 결과 값입니다.
  화면의 100행 또는 그래프의 앞 항목만 내보내지 않습니다.
- 원본 전체 XLSX는 모든 시트와 활성 수식을 포함합니다. 원본 Excel의 고급 객체까지
  완전히 복원하는 기능은 아니며, 기존 V080_APPLY의 호환 범위를 유지합니다.
- 현재 보기 CSV의 수식 실행 위험 문자는 텍스트로 내보냅니다. XLSX 보고서도 값만 기록합니다.

5. 계산 열과 대화
- 행별 SUM/곱셈/IF, 그룹 합계 SUMIF, 정확 일치 VLOOKUP, INDEX/MATCH, 직접 수식 입력.
- {row}는 원본 Excel 행 번호입니다. $B$2 같은 고정 참조와 다른 시트 참조를 사용할 수 있습니다.
- 현재 시트 전체 또는 현재 AND 조건을 만족한 행만 추가합니다. 조건은 저장 시점에 고정되며,
  이후 다른 행이 조건에 맞게 바뀌었다고 자동으로 수식이 새 행에 채워지지는 않습니다.
- 첫 10개 적용 행 결과와 전체 오류 건수를 먼저 확인합니다. 오류가 있으면 수정하거나
  명시적으로 오류를 표시한 채 저장해야 합니다. 숨겨진 오류를 0으로 치환하지 않습니다.
- VLOOKUP의 중복 키는 첫 일치를 사용합니다. 누락 키는 #N/A. 왼쪽 열 조회는 INDEX/MATCH 안내.
- 저장 시 원본 입력과 기존 수식은 유지되고 계산 열을 추가한 전체 통합문서를 다시 계산합니다.
- 서버에서 권한과 표/업무 버전을 다시 확인합니다. 오래된 미리보기는 그대로 저장할 수 없습니다.
- 계산 열 추가 후 원본 편집의 기존 한 단계 되돌리기로 직전 저장을 복원할 수 있습니다.
- 대화 버튼은 기존 AI 편집 화면에 요청·대상 시트를 준비합니다. 누르는 즉시 유료 전송하지 않습니다.
  사용자가 범위/요청을 확인하고 실행한 제안을 검토한 뒤 적용합니다.
- 큰 표 AI 경로는 기존 최대 200행/4,000셀 범위 정책을 유지합니다. 큰 표 전체 계산 열은
  직접 수식/템플릿 미리보기 경로를 사용합니다. 임의 자연어를 항상 정확한 수식으로 보장하지 않습니다.
- 기존 통합문서 20시트, 시트당 100열/50,000행/100만 셀, 프로젝트 200만 셀/수식 20만 개,
  JSON 32MB 및 계산 시간·자원 보호를 유지합니다. 대규모 반복 조회 수식은 제한될 수 있습니다.

6. 권한과 운영
- 기본 테이블은 workspace.sheet.read로 조회합니다. 보고서는 analysis.read가 추가로 필요합니다.
- 보기 저장/수정/삭제는 analysis.manage, 파일은 export, 계산 열은 기존 update/schema/formula/
  draft 및 실제 변경에 해당하는 권한을 검사합니다. 소유 사업/멤버·CSRF·버전 검사도 유지합니다.
- 파일 스트리밍 중에도 세션/권한을 확인합니다. 필터 요청을 SQL 문자열로 만들지 않습니다.
- 개인 설정·공유 DB/기기별 파일 저장·자료 교체·활동/AI 사용량 기반은 유지합니다.
