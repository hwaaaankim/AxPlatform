검증 경계
- 테스트 DB는 H2 메모리 DB이며 운영 MariaDB를 수정하지 않았습니다.
- OpenAI 응답은 테스트 제공자/로컬 응답으로 검증했습니다. 실제 API 비용을 발생시키지 않았습니다.
- 전체 Maven 빌드를 실행한 결과로 표시하지 않습니다. 확보된 의존성으로 JavaCompiler/JUnit을 실행했습니다.
- 브라우저 엔진 설치 파일을 확보하지 못하여 실제 Chromium 화면 캡처/픽셀 단위 확인은 수행하지 못했습니다.
- DOM/서버 검증은 실제 브라우저에서 사용자가 느끼는 속도·레이아웃의 완전한 보증은 아닙니다.
