AxPlatform v0.4.2 — 파일·날짜·목록 동작 개선
적용 대상: v0.4.1이 반영된 프로젝트 / 2026-10-20

1. 적용
- 현재 프로젝트를 백업합니다.
- ZIP 안의 pom.xml, src, qa, docs를 pom.xml이 있는 프로젝트 루트에 같은 경로로 덮어씁니다.
- Eclipse: 프로젝트 새로고침 → Maven 프로젝트 업데이트 → Project Clean → 서버 재시작.
- 브라우저에서 Ctrl+F5로 새로고침합니다. CSS와 모듈 요청 버전을 0.4.2로 통일했습니다.
- 파일별 목록은 docs/V042_CHANGED_FILES.txt에 있습니다.
- 이 ZIP은 변경 파일 패치입니다. 기존 프로젝트 전체를 삭제하거나 ZIP만으로 새 프로젝트를 만들지 마세요.

2. DB·설정
- DB 테이블/컬럼/권한 코드 추가·변경 없음. 실행할 SQL 없음.
- 등록 파일 삭제·복원은 기존 파일 보관 API와 버전 검사를 그대로 사용합니다.
- application.yml 및 config/application-private.yml 변경 없음. 기존 개인 설정을 그대로 사용합니다.
- API 키·DB 비밀번호·업로드 원본·실제 사용자 데이터는 이 패치에 포함하지 않았습니다.

3. 반영 내용
- 모든 파일 입력: 공통 선택 영역, 드래그 앤 드롭, 이름·용량·개수 목록, 개별 ×,
  추가 선택/파일 교체, 전체 비우기, 형식·빈 파일·용량 검사, 업로드 중 잠금.
- 사업별/업무별 첨부: 여러 파일을 선택하고 순차 등록. 성공 파일은 대기 목록에서 제거,
  실패 파일은 사유와 함께 유지. 이미 성공한 파일은 재시도에서 제외.
- 사업별 등록 목록: 검색/초기화/새로고침, 개별 삭제, 선택 삭제, 표시 파일 전체 삭제,
  삭제 파일 조회·복원, 비어 있음/조회 실패 구분, 부분 실패 결과 표시.
- 업무 첨부: 선택 0~20개 표시, 개별 칩 ×, 전체 해제, 등록 목록 새로고침.
- 엑셀·CSV: 1개만 선택, 유효한 파일 교체, 미리보기·워크시트·열 연결,
  가져오기 초기화, 요청 중 파일/인코딩 변경 잠금.
- 날짜: 공통 달력, 월·연도 이동, 오늘/비우기/취소/적용, 직접 ISO 입력,
  날짜 범위/윤년 검증, 키보드 이동, 시간 선택. 동적 생성 폼도 자동 적용.
- 엑셀 날짜 셀·AI 편집 미리보기에도 달력 적용. 잘못된 날짜 문자열은 지우지 않고
  오류로 남겨 수정할 수 있게 했습니다. 열 형식을 날짜로 바꾸면 즉시 달력을 제공합니다.
- 엑셀 행 전체 선택·선택 해제·선택 개수. 행 삭제는 확인 후 편집본에 반영합니다.
- AI 원본: 서버 설정에 따른 선택 개수·총용량 표시, 한도 초과 즉시 차단,
  원본 선택 전체 해제. 이 조작만으로 AI 요청을 보내거나 원본 파일을 삭제하지 않습니다.
- 작업 목록·회원 검색·권한 기능 목록에 초기화, 권한 목록 선택 개수·표시 항목 선택·해제.
- 관리자 회원 등급: 기존 만료 일시를 채우고 유효하지 않은 날짜 전송 차단.
  만료 일시를 건드리지 않은 경우 원래 초 단위 시각까지 보존합니다.
- 계정 찾기: 아이디 찾기에서 숨겨진 이메일의 오류가 제출을 막는 문제 수정.
- 시작 방법을 바꿔도 대기 파일 유지, 미등록 파일이 있으면 페이지 이탈 경고.
  사업 변경 전 대기 파일 처리 확인, 다른 사업으로 잘못 등록되지 않도록 범위 검사.
- 새 동작에 맞춰 사용 안내를 갱신하고, 기존 보라색 디자인/작은 여백/반응형을 유지했습니다.

4. 삭제·초기화의 정확한 의미
- 파일 선택 목록의 × / 전체 비우기: 업로드 전 선택만 해제. 서버 파일 변경 없음.
- 업무 첨부 × / 전체 해제: 해당 업무의 첨부 선택만 해제. 업무 저장 시 반영.
- AI 원본 선택 해제: 다음 AI 요청의 전송 선택만 해제. 기존 업무 첨부는 유지.
- 등록 파일 삭제: 기존 서버의 복원 가능한 보관 처리. 디스크 영구 삭제가 아닙니다.
  해당 원본을 참조하는 업무에서는 복원/첨부 해제 전 다운로드·AI 사용에 제한이 생깁니다.
- 표시 파일 전체 삭제: 최신 200개 조회 범위 중 현재 검색 조건에 표시된 활성 파일만 처리.
  서버의 모든 파일을 일괄 삭제하는 기능으로 표시하지 않았습니다.
- 가져오기 초기화: 선택 파일, 문자 인코딩, 미리보기만 초기화. 이미 편집한 표는 유지.

5. 제한과 검증
- 사진·텍스트 등록: PNG/JPG/JPEG/TXT, 파일당 10MB, 대기 목록 최대 10개.
  등록 후 다음 파일을 추가할 수 있으며 서버 전체 보관 한도를 뜻하지 않습니다.
- 엑셀·CSV: 한 번에 1개, 기존 서버 기준 최대 10MB/20열/200행.
- 업무 첨부: 기존 서버 기준 최대 20개.
- AI 원본: 서버 설정의 개수·합계 용량을 사용. 기본 3개/6MB.
- 통신이 끊겨 성공 여부가 불명확한 파일은 등록 목록을 확인한 뒤 재시도해야 합니다.
- 실제 실행한 검증 및 남은 검수는 docs/V042_VALIDATION.txt를 확인하세요.
