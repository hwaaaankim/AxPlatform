AxPlatform v0.9.1 — 공통 로딩 오버레이
적용 기준: v0.9.0까지 반영한 프로젝트. 추가·수정 파일만 담은 패치입니다.

적용
1. 앱을 종료하고 현재 프로젝트를 백업합니다.
2. ZIP 안 파일을 pom.xml이 있는 프로젝트 루트에 같은 경로로 덮어씁니다.
3. Eclipse Refresh → Maven Update Project → Project Clean → 앱 재실행.
4. 브라우저 강력 새로고침: Windows Ctrl+F5 / Mac Cmd+Shift+R.

SQL·DB 구조·개인 yml 변경은 없습니다. 기존 데이터와 자료를 다시 업로드하지 않습니다.
이 패치에 기존 private 설정을 덮어쓰는 파일이나 실제 비밀 키는 포함하지 않았습니다.

확인할 동작
- Excel/CSV 업로드 → 파일 읽기 → 여러 시트 미리보기 → 편집 초안 반영.
- 미리보기/편집의 이전·다음·페이지 번호 이동, 검색/정렬/보기 초기화, 시트 탭 전환.
- 데이터 센터의 시트/페이지/정렬/조건/보고서 조회, 계산 열 미리보기·저장.
- 전체 시트 저장, 이전 통합문서 불러오기, 원본/현재 보기 파일 다운로드.
- 회원·관리자 화면의 공통 API 요청과 일반 내부 페이지/폼 이동.

처리 중에는 화면을 흐리게 덮고 중앙 카드에 동작명과 움직이는 로딩바를 표시합니다.
8초 이상이면 경과 시간을 보여 줍니다. 측정하지 않은 진행률(예: 80%)은 표시하지 않습니다.
완료/실패/취소 후 해제되며, 여러 요청이 겹치면 남은 처리를 계속 표시합니다.
Excel 계산·정렬처럼 브라우저에서 실행하는 작업도 오버레이를 먼저 그린 뒤 시작합니다.
자동 수식 계산·업무 현황 자동 갱신은 작은 진행 카드로 표시해 입력을 계속할 수 있습니다.
AI의 반복 상태 조회는 기존 AI 진행 상태를 사용합니다. 2초마다 화면 전체를 덮지 않습니다.
